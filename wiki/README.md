# Auto-Ripper Wiki

This wiki explains setup, usage, testing, and debugging for the local Windows MVP app.

## Contents

1. `setup.md` - install/config prerequisites.
2. `usage-cli.md` - full CLI workflow.
3. `testing-validation.md` - validation and regression checks.
4. `debugging.md` - troubleshooting guide.

The desktop app is the supported interface; see the root `README.md`.
The old tkinter GUI (`main.py gui`) was removed in favour of it.
